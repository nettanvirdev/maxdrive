# Code of Conduct

MaxDrive follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short:

- Be respectful and welcoming, whatever someone's background or experience.
- Critique code and ideas, not people. Assume good intent.
- No harassment, insults, sexualized language or imagery, or publishing other
  people's private information.
- Keep discussions on topic and useful for everyone reading later.

This applies in issues, pull requests, discussions and any other project
space, and when representing the project elsewhere.

## Reporting

If someone's behaviour is a problem, contact the maintainer,
[@nettanvirdev](https://github.com/nettanvirdev), privately. Reports are kept
confidential. The maintainer may edit or remove contributions and temporarily
or permanently ban anyone whose behaviour breaks this code, following the
Contributor Covenant's enforcement guidelines.
